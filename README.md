## About Me

I build backend systems that are secure, scalable, and increasingly intelligent. My work sits at the intersection of **Java/Spring Boot engineering** and **applied AI** — from clean REST architecture to LLM-powered features backed by retrieval pipelines.

```java
public final class Rishit extends AIBackendEngineer {

    private final String mission = "Building scalable backend systems for the AI era.";

    @Override
    public void dailyRoutine() {
        solveDSA();            // sharpen problem-solving
        designSystems();       // think beyond CRUD
        buildScalableAPIs();   // engineer for scale
        integrateAI();         // make systems intelligent
        breakThings();         // find the weak points
        fixWhatIBroke();       // understand, don't patch
    }
}
```

| **Backend Engineering** | Design clean, layered REST APIs with Java and Spring Boot |
| **Security** | Spring Security, JWT authentication, role-based access control (RBAC) |
| **AI / LLM Systems** | End-to-end RAG pipelines: parsing, chunking, embeddings, vector search, prompt orchestration |
| **Problem Solving** | Regular DSA practice for strong fundamentals and interview readiness |
| **Currently Exploring** | Distributed systems, caching strategies, API design patterns, microservices |
